# odoo_login_primesoft_tech (Odoo 18)

Adds a show/hide (eye) icon on password fields of the login, signup and
reset-password pages.

## Install
1. Copy folder `odoo_login_primesoft_tech` into your addons path.
2. Restart Odoo: `./odoo-bin -c odoo.conf -u odoo_login_primesoft_tech`
3. Apps -> Update Apps List -> search "PrimeSoft" -> Install.
4. Hard refresh the login page (Ctrl+Shift+R).
