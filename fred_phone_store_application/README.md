# fred_phone_store_application (Odoo 18)

Simple Profit & Loss for a phone store, inside Point of Sale > Reporting.

Sales Price - Cost Price = Profit
Profit - Expenses = Net Profit

Notes:
* Cost price comes from the product "Cost" field (standard price). Set it on every phone.
* Expenses are recorded in Point of Sale > Store Expenses.
* Only POS Managers see the report and expenses.
